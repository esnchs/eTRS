# eTRS – eTransmittal Record System

Eastern Samar National Comprehensive High School (ESNCHS), Borongan

A web portal for tracking transmittal records sent from the school to the
District and Division offices. Staff can search a document by TRF number,
document source, or report name and see whether it is Pending, Released,
or Returned.

## Features
- Search and filter transmittal records
- Status tracking: Pending, Released, Returned
- Official Transmittal Slip that can be printed
- Works on phones and computers
- Data is read from a Google Sheet (the Record Book)

## TRF Numbering
- `d-001` (starts with "d") = District Office
- `0001` (numbers only) = Division Office

## How to Use
Open the website link and use the search box or the filters.
School admins can log in to open the Record Book.
